프론트엔드 개발자 포트폴리오

본 페이지는 프론트엔드 채용 담당자 및 동료를 대상으로 저의 핵심 강점, 주요 활동 경험, 그리고 관찰 가능한 근거 산출물을 소개하기 위해 제작되었습니다.

핵심 역량 및 강점 (STAR)

1. 웹 접근성 표준 준수

상황: 기존 프로젝트에서 키보드만으로 레이어 팝업을 제어할 수 없는 문제 발생

행동: WAI-ARIA 속성을 추가하고 Tab Focus Trap 스크립트를 구현함

결과: Tab 키 및 Esc 키만으로 레이어 팝업 제어가 완벽히 가능해짐

공개 근거: 접근성 구현 소스코드 보기

2. 웹 성능 최적화

상황: 메인 페이지 진입 시 고용량 이미지로 인해 LCP(첫 화면 로딩)가 3초 이상 지연됨

행동: WebP 포맷 변환, Image lazy loading 적용 및 레이아웃 리플로우 최소화 작업 진행

결과: Lighthouse Performance 점수가 62점에서 95점으로 상승함

공개 근거: Lighthouse 측정 결과 보기

3. 문서화 및 협업 개선

상황: 팀 프로젝트 진행 중 API 사양 해석 불일치로 작업 병목 현상 발생

행동: OpenAPI Spec 기반의 API 명세서를 직접 작성하고 Mock Server 구축

결과: 개발 커뮤니케이션 공수 40% 감소 및 전달 오류 0건 달성

공개 근거: 기술 정리 포스팅 보기
