행동: 비빔밥의 재료가 모여 조화를 이루듯 OpenAPI Spec 기반 명세서를 도입해 양측 의견을 수렴·조율함

결과: API 커뮤니케이션 소요 시간이 40% 감소하고 전달 오류 0건을 달성함

공개 근거: API 명세 정리 기록 보기

2. 확실한 몰입과 꾸준함 (좋아하는 것: 치킨, 된장)

상황: 프로젝트 마감 직전 메인 페이지 진입 로딩 속도가 3초 이상 지연되는 문제 발견

행동: 치킨처럼 확실하게 집중하여 이미지 Lazy Loading을 적용하고, 된장처럼 깊이 있게 CSS 최적화를 꾸준히 수행함

결과: Lighthouse 성능 점수가 62점에서 95점으로 상향됨

공개 근거: Lighthouse 측정 결과 보기

상황: 단단한 껍질(조개·게)과 예측하기 힘든 돌발 상황(새)처럼 예외 처리가 누락된 코드 작성 위험 직면

행동: 예외 상황을 철저히 사전 차단하기 위해 입력값 검증 및 널 체크(Null Check) 로직을 전수 작성함
